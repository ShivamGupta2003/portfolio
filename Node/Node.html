Quora Posts

This project is designed to replicate a Quora-style post system, where users can create, edit, and delete posts. It uses a MySQL database to manage the backend, ensuring scalability and efficiency. The project includes tables for users, posts, and comments, all linked by foreign keys to maintain relational integrity. The key focus of the project is to demonstrate database normalization, SQL query optimization, and user management. It features CRUD operations for posts and users, allowing seamless interaction between the frontend and backend to create a real-time question-answer platform like Quora.
